# React Forms

RS School React course task: form handling with two approaches (uncontrolled
components and React Hook Form), accessible modals via React Portals, schema
validation with Zod, and submission history stored in Redux Toolkit.

## Tech stack

- Vite + React + TypeScript
- React Hook Form + Zod (`@hookform/resolvers`)
- Redux Toolkit + React Redux
- Vitest + React Testing Library
- ESLint + Prettier + Husky

## Scripts

- `npm run dev` - start the dev server
- `npm run build` - type-check and build for production
- `npm run lint` - run ESLint
- `npm run format:fix` - format with Prettier
- `npm run test` - run the test suite
- `npm run test:coverage` - run tests with coverage
